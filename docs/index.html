Capabilities

Built like Google Photos.
Living on your disk.

Everything is engineered around one rule: your original files are never touched.

01

Directory-first engine

hellomyphotos reads your disk as-is. Folders map to the UI one-to-one, and originals are mounted read-only so they can never be moved or modified.

02

Built for speed

A virtualized grid renders thousands of thumbnails smoothly, with blurhash placeholders so your gallery feels instant even on large libraries.

03

AI facial recognition

Immich ML detects faces and pgvector groups them into People. Search by who's in the photo, not just by filename.

04

Share

Share any folder with a simple link. Set an expiry, choose whether downloads are allowed, and send it off.

05

Low-bandwidth mode

Flip to 480p delivery and save mobile data without breaking your workflow. Thumbnails and previews are compressed to the byte.

06

Self-hosted privacy

Every byte stays on your hardware. No cloud, no uploads, no trackers. Your photos belong to you, period.

How it works

Your folder tree is the gallery.

Point hellomyphotos at any directory and it indexes what's there, scanning for new files on demand. No import step, no migration, no reorganization.

  • Drop new files in via FTP, SMB, or a sync tool and they appear automatically
  • Originals are mounted read-only and never rewritten
  • Missing files are pruned and their caches cleaned up

Getting started

Up and running in 60 seconds.

The whole stack (frontend, API, workers, PostgreSQL, Redis, and Immich ML) ships as Docker Compose.

1

Grab just the compose file.

mkdir hellomyphotos && cd hellomyphotos
curl -o docker-compose.yml https://raw.githubusercontent.com/KahMeng15/hellomyphotos/main/docker-compose.yml
curl -o .env.example https://raw.githubusercontent.com/KahMeng15/hellomyphotos/main/.env.example
2

Add your photos and set your app URL (change the default database password too).

cp .env.example .env
mkdir -p volumes/media_ro/my_photos

Drop your .jpg, .png, or .mp4 files into volumes/media_ro. They're mounted read-only, so your originals are never touched.

3

Pull the prebuilt images and start the stack.

docker compose pull
docker compose up -d

Then open http://localhost:8000, sign in with the default admin account, and change the password.
